# Visual Learning Studio — Architecture & Design Log

## Overview
Visual Learning Studio is an interactive educational workspace built for the Gemini 4 NYC Hackathon (Element 119 theme). It pairs structured technical study material, an interactive 3D visualization stage, and an AI-guided tutor around a focused curriculum on jet propulsion systems.

## Incremental Build Status

### Phase 1: Dark-Themed Three-Panel Interface Shell (Completed)
- Established the three-panel dark studio layout (`StudioHeader`, `PdfViewerPanel`, `VisualizationPanel`, `AiTutorPanel`), centralized configuration (`src/config/appConfig.ts`), and pure layout/telemetry helpers (`src/utils/studioState.ts`).

### Phase 2: Real PDF Upload, Highlight-and-Ask, and Server-Side Gemini Understanding (Completed)
- **Objective**: Enable students to upload arbitrary PDF documents, select/highlight passages, ask questions about highlighted text, receive structured educational explanations from Gemini, and automatically focus supported jet propulsion visualization stages.
- **Implemented Modules**:
  - `server.ts`: Express full-stack server running on port 3000 with Vite middleware in development, exposing `POST /api/tutor/ask` using the official `@google/genai` SDK (`gemini-4-hydrogen`) and `GEMINI_API_KEY` strictly on the server side.
  - `src/types/tutor.ts` & `src/utils/tutorValidation.ts`: Strict TypeScript interfaces and runtime JSON validation for tutor requests and Gemini structured JSON responses (`mainConcept`, `studentQuestionSummary`, `componentsAndRelationships`, `recommendedVisualization`, `explanation`, `supportedVisualizationComponent`, `visualizationSupported`, `recommendedLayerMode`), tested via `node:test`.

- **Objective**: Replace the 2D schematic with a real procedural 3D turbofan engine rendered via Three.js and React Three Fiber, supporting 8 separately selectable components, smooth camera transitions, cutaway and exploded-view inspection, live airflow/combustion/spool animations, and full synchronization with Gemini's structured JSON visualization commands.
- **Implemented Modules**:

### Honest Limitations
- Generated 3D scenes are simplified conceptual/educational reconstructions with Gemini-estimated proportions and placements rather than CAD-accurate engineering assemblies.
- Spatial layout precision depends on Gemini's structured JSON coordinate estimates; complex multi-axis linkages beyond planar `crank-slider`, `spin`, `reciprocate`, `oscillate-rotation`, `orbit`, and `pulse-scale` are represented conceptually.
- Purely abstract/non-spatial topics (where 3D geometry would mislead) fall back to an explicit limitation explanation and optional 2D diagram.
